# 📚 StudyHub – Smart Learning Platform

**Live Website** 👉 https://studyhub-weld.vercel.app/

StudyHub is a modern web-based platform designed to help college students easily access **syllabus, notes, and academic resources** in one place.  
Built with a clean UI, fast performance, and scalable architecture.

---

## 🚀 Project Overview

StudyHub aims to simplify academic life by providing:
- 📖 Centralized study resources
- 🧑‍🎓 Student-friendly interface
- ⚡ Fast and responsive performance
- 🌐 Web-based access from anywhere

---

## 🛠️ Tech Stack

This project is built using:

- ⚡ **Vite**
- ⚛️ **React**
- 🟦 **TypeScript**
- 🎨 **Tailwind CSS**
- 🧩 **shadcn/ui**
- 🌍 **Vercel** (Deployment)
